# 实验记录与后续工作

## 两轮实验

第一轮采集 50 段，ACT 训练与推理流程跑通，但相机、物块、盒子等场景因素缺少足够固定；用户报告即使物块在原训练位置，真机也未能成功抓取。因此第一轮不能用来评估位置泛化。

第二轮重新固定相机、白臂、盒子和背景，单第三视角录制 60 段，覆盖三个训练位置。合并后的 LeRobot 数据集有 21,378 帧，20 Hz。训练配置为 100,000 步、batch 24，最后一次 `eval_loss=0.2236`。用户报告在三个训练位置均能抓取成功；但将物块偏移约 3 cm 的一次试验未能抓取。这只是该偏移条件下的一次失败观察，并非系统性泛化评测。没有完整记录每个位置的尝试次数，因此不报告“100% 成功率”的统计结论。

推理演进：最初使用 CPU 与约 4 Hz 异步重规划；后改用 GPU，并启用 LeRobot ACT 时间集成，让每个 20 Hz 周期用最新观测重新预测并融合动作。用户主观报告更快、更平顺。需要用相同物块位置、相同起点、固定试次数做 A/B 对比，才可以量化收益。

## 现有局限

- 训练/验证 episode 划分未按**物块位置**隔离；离线损失低不代表新位置成功。
- 数据仅用一个第三视角，没有使用购买套件中的腕部相机。
- 相机帧使用主机接收时间，与机器人状态并非硬件同步。
- 起始姿态检查依赖示范中的实际起点，环境和标定发生变化后需要重审。
- 日志与数据未公开，外部读者无法独立复算成功率和速度。
- 数据采集时的控制限速、推理时的限速/平滑也会影响动作观感，不能全部归因于 ACT 模型。

## 下一步：验证泛化而不是只看训练位置

固定相机、盒子、光照、白臂底座和起始姿态；把物块位置划分为训练点、训练点附近偏移点和完全留出的测试点。每个测试位置重复足够次数并记录是否成功、抓取阶段失败类型、耗时与视频。先用当前模型建立基线，再增加更多位置和连续小扰动的示教，重新训练并在**同一组留出测试点**比较。这样才能区分数据覆盖不足与策略能力不足。
